Windows Vista 不能打开控制面板、显示属性、网络和共享中心、网络连接的解决方法

Posted 2007-01-19 | archive

喜欢精简系统的我，发现系统不能打开桌面点右键，个性化的对话框弹不出来了，网络与共享中心也打不开了，控制面板也显示为空，研究了好久，终于得到答案：

首先 开始 运行 cmd

net start RemoteRegistry
net start netprofm
net start NlaSvc
net start slsvc
net start SLUINotify

搞定。

真的不明白为什么本机必须要开远程注册表服务
