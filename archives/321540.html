OrbitDownloader成功突破LinkGate

Posted 2007-08-21 | archive

最近寻找一款高级的下载软件，希望能够做到

1. 断点续传（最基本的）
2. 多线程下载
3. http/https 带验证
4. Referer引用页下载
5. 修改Uset-Agent
6. 带Cookie下载
7. 支持多种网络硬盘服务商下载（例如liveshare, rapid-share）
8. 多代理下载：有的代理只能下载2MB的东西，所以要智能化
9. 手工添加相同文件的ftp/http地址
10. http/ftp/bt/ed2k 文件交叉下载：例如2个ftp有相同的iso，可以从第一个下载50%，第二个下载50%然后合并起来。并且按照连接速度分配下载任务
11. 下载列表自动获取真实文件，例如 .ram 文件自动获得里面的流媒体地址
12. 基于MIME的嗅探下载拦截，而不是url 的文件后缀名

甚至在DRL求助也没有结果，后来想起了cnBeta上那个出口转内销的新兴下载工具OrbitDownloader，呵呵，果然名不虚传好用，功能好强大！
Orbit Downloader和传统的FlashGet、迅雷都很类似但是又有很多改进的地方，支持的协议HTTP, HTTPS, FTP, MMS, RTSP和RTMP，甚至POST方式下载；支持用户名、密码验证（唯一的遗憾是不支持NTLM，这个还是比较致命的因为很多公司只提供ISA做的代理），支持metalink、magnet和p2p方式下载。还有zip下载预览，磁盘缓存设置；支持IE、Maxthon、Firefox、Opera等多种浏览器集成；和IE7和Vista的兼容性很好；还有，可以手动添加镜像地址（对于SourceForge这样的多镜像网站及其有用），最过瘾的莫过于OrbitDownloader的BrowserContext选项，这里可以自定义Referer引用页、User-Agent、Cookie，甚至自定义HTTP请求头！

OrbitDownloader自带的Grab++工具更是出类拔萃，实现了一个小型的sniffer嗅探器，可以下载youtube、myspace、lastFM上的嵌入式flv影片，或者是Rapidshare的文件地址都可以被嗅探出来！去官站可以看到支持的完整列表。
说了这么多，貌似偏题了，这里说说OrbitDownloader为什么可以突破LinkGate，LinkGate的原理很简单，每一次页面请求都包含一个javascript操作的cookie，下载的时候如果cookie不正确那么就拒绝下载。迅雷操作Cookie的能力很弱，为什么OrbitDownloader就可以呢？分析的IE右键脚本：

<SCRIPT language="VBScript">

Sub Download(Url,Info) On Error Resume Next Set obj=CreateObject("Orbitmxt.Orbit") If Err<>0 Then MsgBox("Orbit not properly installed!") Else Call obj.download(Url, Info, external.menuArguments.document.Url, external.menuArguments.document.cookie) End If End Sub

Sub OnContextMenu() On Error Resume Next Set srcEvent = external.menuArguments.event Set EventElement = external.menuArguments.document.elementFromPoint ( srcEvent.clientX, srcEvent.clientY&nbsp ![;\)](http://static.blogcn.com/wp-includes/images/smilies/icon_wink.gif) If Err<>0 Then Exit Sub End If If srcEvent.type = "MenuExtAnchor" Then Set srcAnchor = EventElement Do until TypeName(srcAnchor)="HTMLAnchorElement" Set srcAnchor=srcAnchor.parentElement Loop Call Download(srcAnchor.href,srcAnchor.innerText) Elseif srcEvent.type="MenuExtImage" Then If TypeName(EventElement)="HTMLAreaElement" Then Call Download(EventElement.href,EventElement.Alt) Else Set srcImage = EventElement Set srcAnchor = srcImage.parentElement Do until TypeName(srcAnchor)="HTMLAnchorElement" Set srcAnchor=srcAnchor.parentElement If TypeName(srcAnchor)="Nothing" Then Call Download(srcImage.href,srcImage.Alt) Exit Sub End If Loop Call Download(srcAnchor.href,srcImage.Alt) End If Elseif srcEvent.type="MenuExtUnknown" Then Set srcAnchor = EventElement Do until TypeName(srcAnchor)="HTMLAnchorElement" Set srcAnchor=srcAnchor.parentElement If TypeName(srcAnchor)="Nothing" Then Call Download(EventElement.href,EventElement.innerText) Exit Sub End If Loop Call Download(srcAnchor.href,srcAnchor.innerText) Else MsgBox("Unknown Event Source """ + srcEvent.type + """") End If End Sub

Call OnContextMenu()

</SCRIPT>

可以发现，Orbit调用了external.menuArguments.document.cookie，所以读取的直接是javascript操作后的cookie，和浏览器直接下载没有区别！顺理成章的突破了LinkGate！
总之，一句话，Orbit Downloader，专业 ！
期待OrbitDownloader推出Linux版本和命令行版本！
