3年过后，重新开始用Firefox

Posted 2007-09-16 | archive

由于IE下没有很好的xHTML/DOM/JS调试工具，所以不得不安装了一个Firefox 2.0.0.6。记得最第一次用Firefox的时候，Firefox还叫Pheonix Browser，跟Opera一个级别的。后来慢慢地发现Firefox1.0 兼容性问题太多，于是弃之不用。加上重装系统后Firefox的配置文档就丢了，很不爽，后来一直用Maxthon，目前用的是TheWorld2。

其实安装完毕Firefox后不要立即启动Firefox，先打开cmd，跳到Firefox的安装目录，运行这个命令：
D:\浏览器及工具\Firefox>firefox.exe -p
或者这个命令：

D:\浏览器及工具\Firefox>firefox.exe -profilemanager
这里可以设定你的 Firefox profile 放到非系统分区

这样可以重装系统，甚至跨Windows/Linux共用一个Firefox配置文档。

第二部是安装Flash插件，我把这个xpi的地址嗅探出来了，用迅雷下载比Firefox速度快得多。

接下来是tweak一下Firefox的UI，打开_Firefox配置文件路径_ /chrome/userChrome.CSS
比如我的是D:\浏览器及工具\Firefox\est_profile\chrome\userChrome.CSS
写入：

#helpMenu{
    display: none;
}

#edit-menu{
    display: none;
}

#file-menu{
    display: none;
}

这样可以隐藏 文件、编辑、帮助 三个鸡肋菜单，然后把工具条全部弄到第一行去，大大的节省了浏览的空间，哈哈。

网上的教程都是通过插件实现的，没有这个来得简洁和直接。其实用户可以去编辑_Firefox安装路径_ \chrome\browser.jar\content\browser\browser.xul把多个菜单合并成一个。

然后装了一些插件，不在多在于精。多了Firefox会非常非常的慢！

3年过去了，Firefox改进了很多，越来越人性化了，但是基于XUL、XPCOM、XML的程序必定很占用内存，速度很慢，还是native binary的IE快点，呵呵。
