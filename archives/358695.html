Vista自带IIS7配置CGI和ISAPI的问题

Posted 2007-08-30 | archive

Vista Ultimate自带的IIS7是全新的界面，所以配置有点摸不着头脑。在 网站 -> 处理程序映射 里添加一个 .php 的ISAPI时，IIS老是提示

---------------------------
添加脚本映射
---------------------------
模块列表中不存在为此处理程序指定的一个或多个模块。如果您尝试添加脚本映射，则 IsapiModule 或 CgiModule 不会显示在模块列表中。
---------------------------
确定
---------------------------

英文是：
One or more of the modules specified for this handler does not exist in the modules list. If you are trying to add a script map the IsapiModule or the CgiModule is not present in the modules list.

Google了半天找不到原因。后来在一个php论坛的帖子里找到了答案。方法很简单，在 控制面板 -> 程序和功能 -> 打开或关闭Windows功能（这几步可以简化为Win+R运行OptionalFeatures） -> Internet信息服务 -> 万维网服务 -> 应用程序开发功能，把下面的全部勾上！重启，成功！
