【原创】Mac OS X Leopard 10.5.2 OSX86 从零入门笔记

Posted 2008-04-27 | archive

Kalyway的10.5.2 osx86光盘出来了，下载、安装、折腾期间等屏幕进度条的时间，花了2个小时把《Mac OS X从入门到精通》看完了。感觉和当年看Windows入门差不多。这本书虽然是讲 10.2 的OS X系统，但是不少操作还是通用的，就像当年我抱一本清华的Win98教程学习WinME和XP一样。

* 首先是按键对应。由于Apple电脑用的不是普通PC的104键盘，所以教程里的按键名称对应如下：

⌥ = Option = Alt
⇧ = Shift = Shift
⌘ = Command/Apple = Win
^ = Control = Ctrl
* Ctrl+单击=右击
* 多选图标：shift+拖选；⌘+拖选
* 有些程序支持“四连击”
* ⌘+O激活一个选定图标
* Shift+单击 = ⌘+单击
* Option+拖动 = 复制。普通拖动：移动。不同盘之间是复制
* Option+⌘+拖动：创建alias
* 窗口左上角从左至右依次是：关闭 最小 最大
* ⌘+W关闭子窗口/标签页 ⌘+M最小化 Shift+⌘+M：慢动作最小化
* 窗口上的图标可以当文件拖动
* ⌘+拖动窗口标题栏：不激活后面的窗口移动位置
* Dock的内容：Application Aliases, Running Applications, File Aliases, Dock Extra(也称Docklings)
* 把一个程序放到前台，其他程序放到后台：⌘+Option+Dock单击
* ⌘+Tab 切换程序 ⌘+Shift+Tab反向切换
* Finder = Mac下的explorer
* 强制推出一个程序：⌘+Option+Escape
* Option+拖动 = 同时改变几个分栏的宽度
* Finder里：Shift+⌘+H打开 H ome。同理有： C omputer， A pplications，Networ k ， U tillities。 G oto Folder
* Finder里⌘+I 查看文件信息
* 新建文件夹⌘+Shift+N
* ⌘+D 建立文件的duplicate
* 复制 - 粘贴 - 撤销 ⌘+C ⌘+V ⌘+Z
* collection：字体集
* admin = wheel = superuser = root
* Terminal里：⌘+↑↓滚动屏幕；PageUp/PageDown上下翻页 ⌘+数字 多个Terminal之间切换
* Terminal里Ctrl+A 光标移动到开头 Ctrl+E光标移动到结尾
* Ctrl+U 清楚光标前所有文字
* !50 执行bash history里第50个命令（我连这个都忘记了，囧）
* Mac里文件路径表示， : 和 / 的作用一样
* ~kir/ k表示用户kirk的主目录

好了，Mac OS X基本上手了。过几天开始研究Cocoa、TextMate、Coda之类好玩的东西。
