一键设置批处理：把Windows Server 2008打造成Workstation

Posted 2008-03-13 | archive

估计很多小白和我一样用Windows Server 2008做自己的桌面OS，因为传说Server 2008“比Vista SP1快”，“内核和Vista SP1完全一样”，“可以通过Vista的OEM激活”，在MSDN Blog（上 下）上看到有人总结了一下安装完毕Server 2008之后改造Workstation的步骤，自己改写了一个批处理版本，双击直接搞定。

核心内容：

1. 安装Windows特性：Telnet客户端、桌面体验、无线管理
2. 开启Theme、Windows Audio、Superfetch
3. 禁用关机理由，登录Ctrl+Alt+Del
4. CPU优化为前台程序而不是后台服务（可能需要重启）
5. 开启各种视觉效果
6. 关闭自动播放
7. 再不关闭IE Sec的情况下，把Internet区域的安全设定为Medium-high

代码采用GPL 2开源 -_-!
:Windows Server 2008 转换为Workstation批处理设置工具 V1.0 :By est :2008-3-12 :可以自行在services.msc里启用Windows Image Acquisition(WIA)增加对摄像头的支持 :需要手动自己关闭DEP :需要手动在GpEdit.msc里修改 Users 组可以关机 :需要手动开启“防火墙屏蔽程序时通知我” :某些情况下需要手动编辑磁盘权限，给Users组加上可读写 :可以使用powercfg -h on来开启休眠 :需要手动更改主题为Windows Aero :至于DX9, DX10, Virtualization, 驱动, 音视频解码包需要用户手动安装

:导入注册表设置
more +40 < "%~f0" > "%temp%\tmp.reg"
regedit /s "%temp%\tmp.reg"

:安装telnet命令、桌面体验、无线支持
pkgmgr /iu:TelnetClient;DesktopExperience;WirelessNetworking

:启用桌面主题
sc config Themes start= auto
sc start Themes

:启用Windows声音
sc config MMCSS start= auto
sc start MMCSS
sc config AudioEndpointBuilder start= auto
sc start AudioEndpointBuilder
sc config Audiosrv start= auto
sc start Audiosrv

:启用Superfetch
sc config SysMain start= auto
sc start SysMain

:结束批处理设置
goto:eof
