Luser

什么是Luser？
v2ex（已被和谐）、mac.6.cn（v2ex的替代者）、footbig的创始人Livid有一篇非常好的文章 luser 速成手册

如果你想快速成为一个 luser，这里有一些提示可以帮助你上路。
给电脑上安装了一个 Ubuntu，然后切换回 Windows，在 Baidu 中输入“Ubuntu 美化”。
从来没有用过 gcc 也不想用。
从来没有在 Unix 下运行过 man man。
在论坛上发帖子问问题，把英文单词拼错，或者是使用同音汉字，甚至用比如 RPWT 之类的汉语拼音简写。
在论坛的帖子的标题里头使用“跪求”之类的字眼。
2001 年或者更早的时候就在电脑上安装过 Linux，但是至今还没有弄清楚究竟怎么装中文输入法。
看到新的开源软件出来，还没有用过就想去帮人家做翻译。
听到别人谈论 Java 然后就下意识地说“那个东西很慢”。
听到别人在用 Windows 就下意识地说“那个东西很不安全”或者“那个是最好用的”。
听到别人在用 Mac 就说“那是有钱人用的”或者“那个东西华而不实”。
会用 C++ 写 Hello World，仅此而已，然后告诉全世界的人“我会 C++”。
对成为 Python 或 PHP 高手抱有极大热情，然后上网找 CHM 格式的电子书却“懒得”去买一本 O'Reilly 的教材。
硬盘里收集超过 1G 甚至更多的 CHM，当然了，不可能看完的。
给别人发电子邮件时候使用 .doc 格式的附件。
不知道甚至也从来没有听说过 luser 一词。

Troll

这种人在mop、天涯、tiexue等重口味论坛比较常见～～
USENET里对这种人叫“Troll”

介绍：http://wiki.woodpecker.org.cn/moin/UsenetTroll

像Chris Qie 这样的在公共论坛[用侮辱性言语挑起骂战并从中获取某种不知名快感的人](http://python.cn/pipermail/python-chinese/2005-November/018477.html)，在Usenet文化中有一个名称: [Troll](http://en.wikipedia.org/wiki/Internet_troll)。

Troll作动词是钓鱼的意思，指那些人发表某种言。由于刚搬进来没多久，我在小区进出的人流中显得陌生。楼房之间隔着四棵棕榈树。内侧两棵棕榈树一样偏高，外两头两棵 论后等待别人的攻击性回复，从 而获得快感。Troll还有一个意思是斯堪的纳维亚神话中一种长相丑陋、爱恶作 剧、令人讨厌的巨人，和那些找骂的人有相似之处，因此也被引申过来形容那些 人，做名词使用。回troll的贴则被称为feed the trolls，即给trolls喂食。

Trolls有很多种，像Chris Qie只是其中一种，即使用种族歧视性语言激怒别人， 好让别人回帖骂他。comp.lang.python上著名的troll: Xah Lee则是长年在各个 script语言讨论组上交叉张贴无关内容或用错误百出的话语对某种语言或者文化进 行攻击。但无论那种troll，他们的目的都是一样的：想通过怪诞的举动引起别人 的注意。这是一种病态心理，是一种未成熟，类似小孩“人来疯”似的举动。

Trolls的存在对公共空间是破坏性的。它们的post会引起很多人回帖，甚至会有情 绪激动者采用谩骂的方式回敬，这些人被称为trollhunter。这些行为正中trolls 的下怀，使他们获得被骂的快乐，从而更加积极的trolling。而且即使 trollhunter的动机是好的，也会给论坛带来不好影响，使其他用户接收到大量无 关信息和攻击性信息，成为受害者。公共空间的和谐性被破坏。

Trolls最愿意看到别人回他的贴，无论是正儿八经指出他的错误还是义愤填膺的对 他谩骂。对一个troll来说，最能让他感到沮丧的则是没有人理他。而我们，正是 应该让他们沮丧，失去trolling的动力。

对待trolls的方法，一方面要靠大家自觉，克制自己回帖的冲动，不给他们喂食。 另一方面，在邮件列表这种有管理员的公共空间，可以向管理员提出封禁trolls的 提案。

RTFM

R ead T he F ucking M anual
现在很多列表里很多问题都是“如何XXX”、“YYY是什么”、“为什么ZZZ”，而这些东西都能在文档里很容易找到答案的话，我们可以十几楼保持队形说：“RTFM”
