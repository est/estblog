Windows Vista/Server 2008下无法使用ISTAP的IPv6故障解决

Posted 2008-09-12 | archive

大二就把IPv6的隧道弄起了，但是到大四才开始用。唉。。。

使用方法：

netsh interface ipv6 isatap set router x.x.x.x

为什么没有效果呢？因为IP Helper服务没有启动。

sc config iphlpsvc start= auto
net start iphlpsvc
