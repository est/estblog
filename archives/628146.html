0x11的Unicode脑残体引起Msxml2解析XML出现-1072896760错误

Posted 2008-12-05 | archive

源文件：    file:///E:/script/xmlhttp/demo.xml
文件位置：   48
行：    3
列:    2
原因：   An invalid character was found in text content.

错误代码： -1072896760
源文本：    ab

一段很简单的XML：

<?xml version="1.0" encoding="UTF-8"?> <rss> ab </rss>

用下面的代码检测错误：

var oXml = new ActiveXObject("Msxml2.DOMDocument");

oXml.load("disc.xml");
oXml.async=false;
oXml.resolveExternals=false;

with(oXml.parseError)
{
WScript.Echo(
"源文件： " + url + "\n" +
"文件位置： " + filepos + "\n" +
"行： " + line+ "\n" +
"列: " + linepos + "\n" +
"原因： " + reason + "\n" +
"错误代码： " + errorCode + "\n" +
"源文本： " + srcText
)
}

出错。因为0x11这个不可打印字符不能被XML解析器解析。今天玩douban的时候发现的。因为一个人的ID是脑残体。

用这个BUG不知道能找到好多网页的出错页面哦～～～
