Howto: Use global hotkey to play/pause Spotify with Hoekey

Posted 2009-04-14 | archive

Add this line to your Hoekey config file (Thanks for the tip, Roar!)

^@F5=Msg|SpotifyMainWindow|793|0|917504 ;Spotify Play/Pause

And the global hotkey for play/pause Spotify in background is Ctrl+Alt+F5

Next song (Thanks Mybeky for the tip!)

^@Right=Msg|SpotifyMainWindow|793|0|720896

So Ctrl+Alt+Right for the next song!

This works for other music players if you change SpotifyMainWindow to a proper window class name, also you can implement this on other hotkey apps like AHK
