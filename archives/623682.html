[ULiPad]Blackboard theme for .py, .pys & .pyw files

Posted 2008-02-11 | archive

I created this syntax highlight theme for ULiPad. Support .py, .pyw & .pys files. The theme is based on ULiPad Black theme, Blackboard theme for Intype. and Blackboard theme for Textmate.

Paste content below to < ULiPad DIR>/conf/stxpython.stx(create one if not exist). Restarting the UliPad.
[styleitems] controlchar = u"fore:#FFFFFF" p_default = u"fore:#FFFFF" number = u"fore:#D8FA3C" classname = u"bold,fore:#FF0000" triple = u"fore:#EABF71" operator = u"fore:#BBBBBB" defname = u"bold,fore:#4179C5" stringeol = u"fore:#408080,back:#E0C0E0,eol" character = u"fore:#E19618" -selback = u"back:#8080FF" bracebad = u"bold,fore:#0000FF" string = u"fore:#61CE3C" bracelight = u"bold,fore:#FF0000" tripledouble = u"fore:#EABF71" commentline = u"italic,fore:#626262" commentblock = u"italic,fore:#AEAEAE" -caretback = u"back:#1A1E2E" keyword = u"bold,fore:#FBDE2D" default = u"fore:#F8F8F8,back:#0C1021,face:Bitstream Vera Sans Mono,size:10" -caretfore = u"fore:#FF0000" linenumber = u"fore:#000000,back:#AAFFAA" identifier = u"fore:#BBBBBB"
