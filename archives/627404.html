Parasitic number

Posted 2008-04-28 | archive

看到和菜头blog上有一篇文章《小学三年级数学题》

一个自然数，把最后一位放在第一位，新数是老数的两倍，求该自然数。

当时的第一反应是：自然数嘛，0。 00 = 00 * 2
当然我怀疑还真有这么一个变 防盗栏杆外已经飘起了雨。盆子在阳台的右角，雨水先落在窗前铁栏杆再顺着花草的叶脉滴到盆子的土壤里。吮吸起左手的西 态的正整数，所以python写了一个穷举。到 100,000也没有跑出来一个结果。郁闷。

看到一个人的回帖，答案是 105263157894736842（刮开可看答案） 。当时就被囧了。小学三年级就可以求出这么大的整数啊，看了百度知道的解题过程，才发现原来这么简单。

找10^n-2模19为0就OK，奥数题吧

看来自己的智商在急剧减低啊。无聊Google了一下这个数字，原来这个数字叫 Parasitic number

生成n-parasitic的公式为：

n * ( 10^(10*n-1) - 1 ) / ( 10 * n - 1)

python里用一个lambda函数表示parasitic = lambda n: n*(pow(10, 10*n-1) -1 ) / ( 10*n -1)

看来数学的精炼真是无与伦比永恒不变的啊。
