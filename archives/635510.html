Howto: Edit Sandboxie Registry Hive Binary File

Posted 2009-01-09 | archive

I always use Sandboxie as a alternative 'Universal Extractor' for software installers in case some setup.exe could not be extracted via UniExtract, it's also a extremely useful unknow application testbed like malware or adware.

Here's an example structure of your Sandbox on a local file system:

\Sandbox\est\DefaultBox
        RegHive
        RegHive.LOG1
        RegHive.LOG2
        RegHive{cbb5c2e5-d153-11dd-aa5b-0017082e7841}.TM.blf
        RegHive{cbb5c2e5-d153-11dd-aa5b-0017082e7841}.TMContainer00000000000000000001.regtrans-ms
        RegHive{cbb5c2e5-d153-11dd-aa5b-0017082e7841}.TMContainer00000000000000000002.regtrans-ms
        user\
        drive\

Wanna to edit the file RegHive? It's infact a standard registry hive binary format which is compatible with RegEdit.exe. But regedit can not directly open it. A thread on CCF inspired me.

The method is simple! Just follow Microsoft's detailed step by step tutorial: Load a hive into the registry (zh_CN中文版:将配置单元加载到注册表)

Now I can make any application portable as I want. LOL

Update: I wrote a Sandboxie Registry Hive Export utillity :-), drag drop RegHive to hiv2reg.js and you'll get RegHive.reg. Merry X'Mas guys!
