Some HTML5 features I'd like to see

Posted 2008-06-01 | archive

  1. Multiple file upload, and stop'n'continue. So user could resume upload some time later. Also multi-threaded upload to speed up.
    1. Support Asynchronous HTTP pushes/pulls. Both chunked request & response
    2. Deal with POST data. Sometimes I wrote something long. submit and, oops, '404 Page not found'. Then click 'back' there's blank textbox & nothing left.
    3. Simplify HTML tags for faster render on mobile devices. HTML5 should not add MORE but cut LESS. Save more CPU and memory!
    4. Do not make a markup language like XML crap. Not data type attribute. But more metadata
