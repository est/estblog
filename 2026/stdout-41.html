一键清理所有高科技水印工具 「蒸矢」for macOS

Posted 2026-11-05 | stderr

V站看到 警告！分享淘宝截图可能给你带来危险

于是有个很久的 idea 终于得到实施了。

https://github.com/est/Distill-SVG

把蒸馏成矢量图 SVG ，简称 蒸矢 😃

市面上有很多AI辅助把照片转SVG的，但其实矢量图不适合拿来做这事。GUI这类大量色块的截图倒是非常适合。

发行两个 dmg

  • 13MB 完整版，适合普通用户 DistillSVG-arm64-full.dmg
  • 400KB 适合能自己折腾 python 环境的。DistillSVG-arm64-python.dmg

后者需要 pip 装 cv Pillow 等。可以共享已有环境避免重复安装

也可以自己 git clone 命令行操作

转文字通过 macOS 自带 OCR ，图标、头像等会尽可能给你扣出来保留

对于常见的聊天界面加水印够用了。文字识别有问题，你用文本编辑器打开 SVG 改下就行。

如果你说水印藏在头像里，那的确（暂时）还没啥好的办法

目前对于图标太多，需要多处定位的效果很差，蒸矢变蒸💩了。一般的稀疏聊天界面勉强还行
