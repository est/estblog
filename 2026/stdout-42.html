保留集合

页面理论上可以 preventDefault 任何键，但浏览器 chrome 的键必须先赢：ShortcutOverride 事件里命中保留键就忽略 override、交给浏览器 QAction，否则接受 override、交给页面。

Ladybird 没有绑定的键（别按了以为坏了）

键 结论
Ctrl+P 打印 无 StandardKey::Print 绑定
Ctrl+S 保存 无 StandardKey::Save 绑定；右键"另存为"走菜单动作，无快捷键
F11 全屏 只是被当作普通键转发给页面（UI/Qt/WebContentView.cpp:702 把 F11 映射成 Key_F11）
Ctrl+C 中断 / Ctrl+L 清屏 属于终端组件，不是主浏览器页面

验证：grep -rn "StandardKey::Print\|StandardKey::Save\|StandardKey::FullScreen" UI/ Libraries/ 无结果；终端组件见 Libraries/LibWebView/TerminalInputParser.cpp、TerminalWebView.cpp:517-527。

  • 未列出的键默认归页面：LibWeb 的 EventHandler.cpp 里没有 Mod_Ctrl 组合分支（grep -rn "Mod_Ctrl" Libraries/LibWeb/HTML/EventHandler.cpp 无结果）。
  • HTML accesskey（Alt+字母）是规范级的"页面快捷键"，实现在 Libraries/LibWeb/HTML/HTMLElement.cpp:2719（access_key_label()），实际组合依赖平台与页面属性。
  • 页面 JS 自己注册的快捷键（如 Gmail 的 c）不归浏览器管，本表自然也搜不到。
