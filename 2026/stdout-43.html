Ladybird Browser Launch Options

Posted 2026-11-27 | stdout

ladybird 的全部启动参数。权威来源是它自己：

Meta/ladybird.py run ladybird -- --help
ARGSPARSER_EMIT_MARKDOWN=1 Meta/ladybird.py run ladybird -- --help

标注 隐藏 的参数不进 --help，但照常能用（parse() 不看 hide_mode）。

命令行参数

位置参数

参数 取值 / 示例 说明
url 取值 [url ...]，如 ladybird example.com a.html 启动时打开的 URL，可省略、可多个
URLs to open at startup

Headless 与窗口

参数 取值 / 示例 说明
--headless 取值 [=mode]，如 --headless、--headless=text 不开窗口跑。mode ∈ screenshot（默认，省略值即取它）、layout-tree、text、manual、terminal（非 Windows）
Run without a window; screenshot is the default
--screenshot-delay 取值 <seconds>，如 --screenshot-delay 3 截图前等几秒（仅 screenshot 模式）
Seconds to wait before the screenshot
--screenshot-path 取值 <path>，如 --screenshot-path out.png 截图存哪（仅 screenshot 模式）
Where to save the screenshot
--window-width 取值 <pixels>，如 --window-width 1280 视口宽，默认 800，目前仅 headless 生效
Viewport width, default 800
--window-height 取值 <pixels>，如 --window-height 720 视口高，默认 600，目前仅 headless 生效
Viewport height, default 600
--device-pixel-ratio 取值 <ratio>，如 --device-pixel-ratio 2 DPR，默认 1，仅 headless terminal 模式
Device pixel ratio, default 1

Profile 与进程统计

Replace an unresponsive earlier browser
--stats-log-dir 取值 <path> 进程统计（JSON lines）写到哪；Android 不注册
Directory for process statistics

隐藏与内部参数

参数 取值 / 示例 说明
--webdriver-browser-mach-server-name 取值 <name>，隐藏，仅 macOS 浏览器 WebDriver IPC 的 Mach server 名
Mach server for WebDriver IPC
--webdriver-browser-path 取值 <path>，隐藏，非 macOS 浏览器 WebDriver IPC 路径
Path to the WebDriver IPC
--ui-info 取值 <hex>，隐藏 UI 交给 Hub 的启动信息

Mach server for the Hub to reach the UI
--ui-pid 取值 <pid>，隐藏 Hub 结束时一并结束的 UI 进程 PID
PID of the UI process the Hub ends with
